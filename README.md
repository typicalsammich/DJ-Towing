# DJ's Towing LLC Website

Static multi-page website for DJ's Towing LLC.

## GitHub
Upload the contents of this folder to the repository root. `index.html` is the homepage.

## Vercel
Import the GitHub repository into Vercel. No framework or build command is required. The site is plain HTML, CSS and JavaScript.

## Domain
SEO canonicals, sitemap and structured data are configured for `https://www.djstowingla.com`. If a different final domain is selected, replace that hostname in all HTML files, `robots.txt`, and `sitemap.xml` before launch.

## Before launch
Connect the request form to the production Towbook workflow or form endpoint, verify the final service area and hours, and connect the final domain in Vercel.
